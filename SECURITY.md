# Bezpečnostní politika

Agent a koncentrátor jsou produkty s digitálními prvky podle CRA; výrobcem je DynamicData

## Hlášení zranitelnosti

Zranitelnosti **nehlaste veřejně**. Použijte soukromé hlášení na GitHubu: záložka **Security → Report a vulnerability**.
Uveďte verzi (`contix-agent version`), roli (agent / koncentrátor), OS, popis, kroky k reprodukci a dopad.
Přijetí potvrdíme do 5 pracovních dnů; kritické a vysoké zranitelnosti opravujeme přednostně opravnou verzí.

## Vydání

Každé vydání je podepsané klíčem vydavatele a má SBOM (CycloneDX). Agent i koncentrátor přijmou aktualizaci
jen s platným podpisem vydavatele a nikdy starší verzi.
